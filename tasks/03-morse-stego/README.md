## Как это решается: ход мыслей и логика

### Шаг 1: Первичная рекогносцировка файла
Смотрим на свойства `task_image.jpg`:
- Расширение говорит `.jpg`, но `file task_image.jpg` выдаёт:
  `PNG image data, 200 x 200, 8-bit/color RGB`.
- Разрешение всего $200 \times 200$, все пиксели абсолютно белые `(255, 255, 255)`.
- Нормальный белый PNG такого размера весит меньше 400 байт. Однако этот файл весит **537 958 байт** (больше полумегабайта).

Вывод: внутри зашита полезная нагрузка (Payload).

### Шаг 2: Извлечение спрятанных данных
Инспектируем PNG-структуру по чанкам:
1. `IHDR` (размер, глубина цвета)
2. `sRGB`, `gAMA`, `pHYs`
3. `IDAT` (сжатые белые пиксели)
4. `IEND` (конец структуры PNG на смещении 606 байт)

Сразу за байтами чанка `IEND` начинается хвост длиной 537 352 байта.  
Первые байты хвоста:
```text
---CTF_MORSE_SPLIT_MARKER---RIFF...WAVEfmt ...
```

Автор таски приклеил к картинке аудиофайл формата WAV, предварив его текстовым разделителем `---CTF_MORSE_SPLIT_MARKER---`.

Отрезаем байты от маркера до конца файла и сохраняем как [`morse.wav`](file:///home/valentin_stars/INFO-SEC-LABS-CTF/tasks/03-morse-stego/morse.wav).

### Шаг 3: Аудиоанализ и морзянка
Характеристики полученного аудио:
- Моно, 8-бит, частота дискретизации 8000 Гц.
- Длительность: 67 секунд.
- При прослушивании или открытии в Audacity слышен четкий телеграфный сигнал (азбука Морзе) на частоте около 800 Гц.
- Параметры импульсов:
  - Точка (`.`): ~60 миллисекунд
  - Тире (`-`): ~180 миллисекунд (в 3 раза длиннее точки)
  - Пауза внутри буквы: ~60 миллисекунд
  - Пауза между буквами: ~180 миллисекунд
  - Пауза между словами: от 350 миллисекунд

Не нужно сидеть с секундомером и карандашом: в 15 строк кода на Python мы вычисляем огибающую амплитуды сигнала и автоматически преобразуем точки и тире в текст.

Результат распознавания Морзе:
```text
K5UGC5BHOMQHI2DBOQQHEZLEEBZG65LOMQQHI2DJNZTSAUTZOVVSA2LTEB2G65DBNRWHSIDPMJZWK43TMVSCA53JORUD6===
```

### Шаг 4: Декодирование Base32 и разгадка
Строка состоит исключительно из заглавных латинских букв, цифр 2-7 и заканчивается на три знака равенства `===` — это классический **Base32**.

Декодируем:
```python
import base64
s = "K5UGC5BHOMQHI2DBOQQHEZLEEBZG65LOMQQHI2DJNZTSAUTZOVVSA2LTEB2G65DBNRWHSIDPMJZWK43TMVSCA53JORUD6==="
print(base64.b32decode(s).decode())
```

Получаем английскую загадку:
> *"What's that red round thing Ryuk is totally obsessed with?"*  
> *(Что это за красная круглая штука, от которой Рюк без ума?)*

Рюк — бог смерти (синигами) из культового аниме/манги *Death Note* (*Тетрадь смерти*). На протяжении всей истории он зависим от сочных красных **яблок** (**`apple`**).

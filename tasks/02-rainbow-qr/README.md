# Task 02: Rainbow QR (Сборка спектрального QR-кода)

> **Категория**: Crypto / Misc / OSINT  
> **Сложность**: Easy  
> **Ключевой файл**: `Task2.rar` (пароль берется из Task 1)

---

## В чем суть задачи

Автор любит слушать музыку и просит узнать, откуда родом загаданный артист. Паролем к архиву является ID папки из первой задачи в кубе:

$$6741^3 = 306318327021$$

Внутри запаковано 7 узких вертикальных картинок (`1.png` – `7.png`). При решении задачи флаг дополняется названием страны исполнителя:

```text
Flag_{filename.png_country_}
```

## Как это решается: ход мыслей и логика

### Шаг 1: Распаковка
Архив `Task2.rar` запакован в формате RAR5 с шифрованием заголовков. Открываем его утилитой `7z`:

```bash
7z x -p306318327021 Task2.rar
```

Получаем 7 файлов: `1.png`, `2.png`, `3.png`, `4.png`, `5.png`, `6.png`, `7.png`.

### Шаг 2: Анализ геометрии
Смотрим размеры картинок:
- `1.png`: 244 x 1710
- `2.png`: 245 x 1710
- `3.png`: 244 x 1710
- `4.png`: 245 x 1710
- `5.png`: 244 x 1710
- `6.png`: 244 x 1710
- `7.png`: 244 x 1710

Высота у всех одинаковая — 1710 px.  
Сумма ширин: $244 + 245 + 244 + 245 + 244 + 244 + 244 = 1710\text{ px}$.  
Перед нами квадратное изображение $1710 \times 1710$, разрезанное на 7 вертикальных полос.

### Шаг 3: Порядок полос (Радуга)
Если склеить полосы просто по порядку `1, 2, 3, 4, 5, 6, 7`, получается каша с разорванными метками позиционирования QR (finder patterns).

Но смотрим на цвета полосок:
- Полоса `7`: Красный
- Полоса `4`: Оранжевый
- Полоса `6`: Жёлтый
- Полоса `1`: Зелёный
- Полоса `5`: Голубой
- Полоса `2`: Синий
- Полоса `3`: Фиолетовый

Это классическая радуга — мнемоника **«Каждый Охотник Желает Знать Где Сидит Фазан»**:

| Порядок в спектре | Цвет | Номер файла |
|---|---|---|
| 1. **К**аждый | Красный | `7.png` |
| 2. **О**хотник | Оранжевый | `4.png` |
| 3. **Ж**елает | Жёлтый | `6.png` |
| 4. **З**нать | Зелёный | `1.png` |
| 5. **Г**де | Голубой | `5.png` |
| 6. **С**идит | Синий | `2.png` |
| 7. **Ф**азан | Фиолетовый | `3.png` |

Правильный порядок соединения полос слева направо: **`[7, 4, 6, 1, 5, 2, 3]`**.

При такой склейке угловые квадраты QR-кода сходятся пиксель в пиксель.
